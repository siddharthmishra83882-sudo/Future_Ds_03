# 📊 College Event Feedback Analysis

## 📌 Internship Project
This project was developed as part of my Data Analytics Internship.  
The objective of this project is to analyze college event feedback data to understand
participant satisfaction, sentiment trends, and provide actionable recommendations
for improving future events.

---

## 🛠 Tools & Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Natural Language Processing (Sentiment Analysis)
- Word Cloud
- Google Colab
- TextBlob

---

## 📂 Dataset Overview
The dataset contains feedback collected from participants of various college events.
It includes:
- Event name and department
- Event type (Workshop / Seminar)
- Participant ratings (1–5)
- Textual feedback comments

Both quantitative and qualitative analysis techniques were applied.

---

## 📈 Analysis Performed
- Rating distribution analysis
- Event-wise satisfaction comparison
- Sentiment analysis of textual feedback
- Word Cloud visualization to identify common themes
- Comparison between workshops and seminars
- Department-wise performance analysis

---

## 🔍 Key Insights
- Certain events consistently received high satisfaction ratings (4 and above)
- Workshops were rated higher than seminars, indicating preference for hands-on learning
- Common complaints were related to time management and scheduling
- Some departments consistently organized highly rated events

---

## ✅ Recommendations
- Improve scheduling and time management
- Increase the number of interactive workshops
- Enhance logistical planning and coordination
- Maintain high-quality speakers and relevant content
